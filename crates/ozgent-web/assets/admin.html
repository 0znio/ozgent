Who may connect
Allow
One address or range per line, IPv4 or IPv6. Used only in "only the addresses allowed" mode.
Deny
Always refused, in either mode, before anything else.
Host names
Names this server answers to besides localhost and bare addresses — a LAN name, or what a reverse proxy forwards. Any other name is refused, which is what stops a web page from reaching this server through a domain it points here.
Trusted proxies
Only these may say, in X-Forwarded-For, who a request is really from.
Limits
0 means no limit. This machine is not rate-limited. The request size applies after a restart.
